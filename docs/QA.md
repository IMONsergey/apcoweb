# Quality assurance

The test matrix is implemented in `tests/landing.spec.ts`. Results are generated by Playwright, not inferred from a build alone.

## Coverage

- 11 widths: 1920, 1600, 1440, 1366, 1280, 1024, 768, 430, 390, 360, 320.
- Chromium, Firefox and WebKit engines. Browser emulation is not a substitute for physical iPhone/Android testing.
- Asset loading, runtime errors, content geometry and internal anchor validity. Intentional clipped decorative contours are excluded from text overflow checks; their content children are checked separately.
- Disclosure navigation, Escape/focus restoration, mobile drawer, carousel end positions, native FAQ expansion, long text, validated search handoff, comparison and pricing dialogs.
- Automated axe scans at desktop and phone widths. These do not establish complete WCAG conformance.
- Animation frame changes, pause and reduced-motion behavior.
- Height-aware desktop scenes at 1200×1000, 1280×600, 1536×740 and 1920×950 in both languages; readable copy, carousel bounds, full sections below navigation, resize state and natural flow at 1280×480. Simulated CSS viewports model reduced browser height; no physical Windows check is claimed.

The full-page screenshots are stored in Playwright test output. Representative review captures and an execution summary are saved in this repository after a successful run.

## Limits

No production API, account creation or checkout is exercised. Search handoff is intercepted in tests to avoid sending test queries to the real product. Current product destinations are preserved, not recreated.
